# 📖 道德經 · 讀與寫

> 王弼本　八十一章　逐句白話　｜　可用 Apple Pencil 手寫筆記

## 功能

- **閱讀**：目錄 → 選章 → 點原文句子，下方浮現白話（沿用《金剛經》互動閱讀的做法）。「白話全開」可一次顯示整章。
- **書寫**：按「✏️ 書寫」後，Apple Pencil 直接在紙面任何地方寫字、畫線。
  - 手指只負責捲動頁面（防手掌誤觸）；要用手指寫，打開「手指也寫」。
  - 黑／紅／藍筆、螢光筆、三種粗細、橡皮擦（整筆擦除）、復原、清除本章。
  - 每章底部有「我的心得」橫線空白區。
  - 版面固定，點開白話不會讓文字位移，筆記不會錯位。
- **儲存**：筆跡以向量存在瀏覽器（IndexedDB），自動儲存。目錄頁可「匯出／匯入」備份 JSON。

## 在 iPad 使用

1. Safari 開啟網址。
2. 分享 → **加入主畫面**，之後像 App 一樣全螢幕開啟，第一次連線後也能離線閱讀。
3. 定期在目錄頁按「匯出全部筆記」，存到「檔案」App（iCloud 雲碟）。

> ⚠️ 筆記存在「這台裝置的這個瀏覽器」。清除 Safari 網站資料、或網址（網域）改變，筆記就看不到了，所以要備份。
